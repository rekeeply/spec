# Authentication Boundary

- правила аутентификации определяет core;
- проверку учетных данных и выпуск сессии выполняет core;
- клиент только передает аутентификационные данные в core-контракт и хранит клиентские артефакты сессии;
- доступ к данным без активной валидной сессии запрещен.
