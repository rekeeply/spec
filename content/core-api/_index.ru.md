# Core API

Платформенно-нейтральная спецификация исполнения core.

## Границы раздела

- Здесь описывается контракт core: доменная модель, инварианты, состояния и обязательные правила поведения.
- Здесь НЕ описываются клиентские UX-флоу, команды интерфейса и визуальное поведение.
- Клиенты (CLI и другие) ДОЛЖНЫ использовать этот контракт, а не переопределять доменные сущности.
- Практическое использование для пользователя описывается в разделах клиентов.
- Baseline формата переноса библиотеки зафиксирован в [Формате переноса библиотеки](../library-transfer-format/).
- Baseline настроек зафиксирован в [Модели настроек](../settings-model/).
