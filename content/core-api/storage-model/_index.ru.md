# Модель хранения

Модель хранения core состоит из двух основных доменов: [Library](library-model/) и [Raw](raw-model/).

Термины зафиксированы в [Глоссарии](/appendices/glossary/).

Правила сессии и синхронизации определены в [Модели аккаунта](/core-api/account-model/) и [Модели исполнения](/core-api/execution-model/).

- `Library` — структурированное пространство хранения для основной организованной работы.
- `Raw` — неструктурированное пространство хранения для быстрого сохранения и последующего разбора.

## Точка входа доступа

```
User (после `unlock`)
  |
  +--> Library
  |
  +--> Raw
```

## Граница доменов

- `Library` хранит структурированный контент для основной организованной работы.
- `Raw` хранит неструктурированные быстрые сохранения для последующего разбора.
- Перенос из `Raw` в `Library` выполняется как явная операция.
