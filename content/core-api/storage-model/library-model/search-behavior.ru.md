# Поведение поиска

## Базовое правило

- `Search` и `Preset` ДОЛЖНЫ использовать один и тот же query-движок и одинаковую семантику.

## Search vs Preset

- `Search` по умолчанию является временным (ephemeral) и не сохраняется, пока пользователь явно его не сохранит.
- `Preset` — явно сохраненное определение поиска.
- При изменении текущего поиска или перезапуске сессии библиотеки предыдущий временный результат поиска удаляется.
- Между сессиями сохраняются только явно сохраненные пресеты.

## Измерения поиска

- Поиск ДОЛЖЕН поддерживать структурные условия по `status`, `priority`, `rating`, `recommendation`, `favorite`, `archived`, `content_type`, `content_subtype`.
