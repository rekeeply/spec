# person

Обязательные:

- `display_name` (`text`) - основное отображаемое имя персоны в библиотеке.

Опциональные:

- `full_name` (`text`) - полное имя.
- `aliases` (`tag_list`) - альтернативные имена/псевдонимы.
- `born_year` (`integer`) - год рождения.
- `died_year` (`integer`) - год смерти (если применимо).
- `nationality` (`text`) - национальность/страновая принадлежность.
- `roles` (`multi_enum`) - роли/профессии.
- `known_for` (`long_text`) - краткое описание, чем известен.
- `official_site` (`url`) - официальный сайт/профиль.
- `external_ids` (`json`) - внешние идентификаторы (например, ORCID, Wikidata, IMDb).

Примечания по подтипам:

- `person/author` обычно использует `roles`, `known_for` и ссылки на публикации.
- `person/speaker` обычно использует медиа/профильные ссылки и тематические заметки.
- `person/researcher` обычно использует `external_ids` и исследовательский контекст в заметках.
- `person/creator` обычно использует ссылки на платформы/профили.
