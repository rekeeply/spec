# misc

Поля:

- `kind_note` (`text`) - короткое пояснение, что представляет запись.
- `external_id` (`text`) - опциональный внешний идентификатор.
- `extra_metadata` (`json`) - расширенный произвольный объект метаданных.

Примечания по подтипам:

- `misc` не имеет подтипов по умолчанию.
