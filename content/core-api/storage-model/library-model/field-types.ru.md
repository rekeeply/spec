# Типы полей

## Scope

- Раздел фиксирует разрешенные значения `field_type` для пользовательских полей.
- Для всех типов полей параметр `required` настраиваемый (`true | false`).
- Значения по умолчанию настраиваются там, где это поддерживается типом поля.

## Разрешенные типы полей

- `text` - короткий текст.
  - Валидация: `min_length` (опционально), `max_length` (опционально), `pattern` (опционально), `trim_on_save` (опционально).
  - По умолчанию: `default_value` (опциональная строка).

- `long_text` - длинный многострочный текст.
  - Валидация: `min_length` (опционально), `max_length` (опционально), `trim_on_save` (опционально).
  - По умолчанию: `default_value` (опциональная строка).

- `boolean` - логическое значение true/false.
  - Валидация: только проверка типа.
  - По умолчанию: настраиваемый `default_value` (опциональный boolean).

- `integer` - целое число.
  - Валидация: `min_value` (опционально), `max_value` (опционально), `step` (опционально, default `1`).
  - По умолчанию: `default_value` (опциональный integer).

- `decimal` - дробное число.
  - Валидация: `min_value` (опционально), `max_value` (опционально), `precision` (опционально).
  - По умолчанию: `default_value` (опциональный decimal).

- `date` - календарная дата без времени.
  - Валидация: корректный формат даты.
  - По умолчанию: `default_value` (опциональная дата), `default_now` (опционально).

- `datetime` - дата и время.
  - Валидация: корректный формат datetime.
  - По умолчанию: `default_value` (опциональный datetime), `default_now` (опционально).

- `duration` - длительность.
  - Рекомендуемое хранение: нормализованный integer в секундах.
  - Валидация: значение ДОЛЖНО быть `>= 0`.
  - По умолчанию: `default_value` (опциональная длительность).

- `url` - URL-ссылка.
  - Валидация: корректный формат URL; разрешенные схемы задаются реализацией.
  - По умолчанию: `default_value` (опциональный URL).

- `email` - email-адрес.
  - Валидация: корректный формат email.
  - По умолчанию: `default_value` (опциональный email).

- `phone` - телефонный номер.
  - Валидация: корректный формат телефона (строгость implementation-defined).
  - По умолчанию: `default_value` (опциональный phone).

- `enum` - выбор одного значения из списка.
  - Валидация: `options` обязательны и задаются как `value_key + label`; сохраненное значение ДОЛЖНО присутствовать в `options`.
  - По умолчанию: `default_value` (опциональный `value_key` из `options`).

- `multi_enum` - выбор нескольких значений из списка.
  - Валидация: `options` обязательны; все сохраненные значения ДОЛЖНЫ присутствовать в `options`; `min_selected`/`max_selected` опциональны.
  - По умолчанию: `default_value` (опциональный массив `value_key`).

- `ref` - одна ссылка на другую запись контента.
  - Валидация: ссылка ДОЛЖНА указывать на существующую запись той же библиотеки.
  - По умолчанию: `default_value` (опциональный reference id).

- `ref_list` - несколько ссылок на другие записи контента.
  - Валидация: все ссылки ДОЛЖНЫ указывать на существующие записи той же библиотеки; значения уникальны; `min_items`/`max_items` опциональны.
  - По умолчанию: `default_value` (опциональный массив reference id).

- `json` - расширенный произвольный JSON-объект.
  - Валидация: корректный JSON; опциональная проверка по схеме.
  - По умолчанию: `default_value` (опциональный JSON-объект).

- `file_ref` - ссылка на файл (путь/URI/идентификатор).
  - Валидация: корректный формат пути/URI/ссылки; проверка доступности файла опциональна.
  - По умолчанию: `default_value` (опциональная file reference).
