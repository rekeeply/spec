# Rekeeply Specification

Спецификация описывает core-контракт и клиентские реализации для личной системы
управления контентом: единое хранение материалов, прогресс, заметки и быстрый поиск.

Цель — превратить хаотичное "на потом" в управляемый поток:
сохранить -> пройти -> зафиксировать -> быстро найти.
