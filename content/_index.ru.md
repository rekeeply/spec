# Rekeeply Specification

Rekeeply — личная система управления контентом для digital garden.
Она дает единое место для материалов, прогресса и заметок с быстрым поиском.

## 1. Разделы спецификации

Спецификация состоит из следующих частей:

- [Introduction](introduction/)
- [Core API](core-api/)
- [Client Profiles](client-profiles/)
- [Appendices](appendices/)
- [Changelog](changelog/)

## 2. Введение

Цель Rekeeply — превратить хаотичное "на потом" в управляемый поток:
сохранить -> пройти -> зафиксировать -> быстро найти.

Core описывается платформенно-нейтрально. Специфика клиентов (включая CLI)
вынесена в раздел `Client Profiles`.

## 3. Архитектура (базовые договоренности)

Rekeeply определяет API и runtime-контракты для синхронизации состояния
контента между клиентами, локальным core runtime и опциональными удаленными
сервисами.

Модель поддерживает:

- локальный режим работы по умолчанию (offline-first);
- опциональную синхронизацию по защищенному каналу;
- одну активную базу в рамках одной активной сессии;
- несколько баз в рамках одного аккаунта;
- расширяемость клиентов без изменения core-логики.
