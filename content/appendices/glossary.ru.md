# Глоссарий

Фиксированные канонические термины, используемые в спецификации.

- `Account` — верхнеуровневый пользовательский доменный контекст в core.
- `Session` — аутентифицированный runtime-контекст, привязанный к одному `account_id`.
- `Library` — структурированный домен хранения для организованной работы.
- `Raw` — домен неструктурированного capture уровня аккаунта.
- `active_library_id` — выбранная библиотека для `library-scoped` операций.
- `library-scoped` — операция/данные, требующие активный контекст библиотеки.
- `account-scoped` — операция/данные, требующие только контекст аккаунта в сессии.
- `unlock` — открытие сессии после валидации учетных данных.
- `sync` — асинхронная синхронизация данных между локальным и удаленным runtime.
- `promote` — явный перенос данных из `Raw` в `Library`.
