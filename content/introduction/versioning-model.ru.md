# Versioning Model

В Rekeeply используются три независимых версии:

- `spec vS.T` — версия спецификации (контрактов);
- `core vX.Y` — версия реализации core runtime/API;
- `client vA.B` — версия реализации клиентского профиля (например, CLI).

Связь между ними:

- `spec` определяет контракт (что должно быть);
- `core` декларирует, какие версии `spec` поддерживает;
- `client` декларирует, с какими версиями `core` совместим.

Правило версий:

- major (`X`) — breaking changes;
- minor (`Y`) — обратно-совместимые изменения.
